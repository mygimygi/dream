# 파도섬 이야기 (Wave Isle)

바람이 멎은 작은 섬에서 달진주를 되찾는, 3D 디오라마 스타일의 오리지널 액션 어드벤처 게임입니다.
TypeScript + Three.js(WebGL) + Vite로 만들었고, 외부 3D 에셋 없이 모든 모델, 셰이더, 음악, 효과음을 코드로 직접 생성합니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 에 배포용 빌드
npm run preview    # 빌드 결과 미리보기
node scripts/inline.mjs   # dist/wave-isle-single.html: 파일 하나로 된 버전
```

`dist/` 폴더를 정적 호스팅(GitHub Pages, Netlify, Vercel, S3 등)에 그대로 올리면 됩니다. 상대 경로(`base: './'`)로 빌드됩니다.
URL에 `?q=low|medium|high`를 붙이면 그래픽 품질을 강제할 수 있습니다.

## 진행 (메인 스토리 9장)
1. 소라 할머니 → 2. 산호검 → 3. 등대 폐허의 등불 → 4. 물빛 동굴 보스(가시고둥왕) → 5. 사원에 달진주 →
6. 폭탄으로 이끼숲 바위벽을 부수고 숲의 수호자 처치(바람 활 획득) → 7. 보물지도 ②로 해변을 파서 대왕소라게 처치 →
8. 두 바람돌을 제단에 바치고 하늘 정원에서 폭풍해파리(눈이 열릴 때 활) 처치 → 엔딩.

## 확장 콘텐츠
- **일반 퀘스트 7개**: 장난감 배, 할머니 안경, 버섯 수프, 첫 낚시, 단단한 광석, 딱정이 퇴치, 다친 늑대. 머리 위 `!`(진행 가능) `?`(보고 대기).
- **도구**: 삽(반짝이는 흙·보물지도 장소 파기), 폭탄(금 간 바위·보스 약점), 바람 활(표적·보스 눈), 낚싯대, 등불, 거인의 장갑(무거운 바위).
- **보물**: 땅속 보물 12곳(밤에만 파지는 곳 포함), 보물지도 3장(그림 단서), 금 간 바위 6개, 전설의 상자, 하트 조각 4개 → 하트 1칸.
- **낚시**: 물고기 12종(장소·시간·희귀도별), 입질 타이밍 + 게이지 미니게임, 최대 크기 기록, 낚시 대회(2분, 순위 보상).
- **요리**: 재료 채집(버섯·사과·채소·구름풀·게살·물고기), 냄비 2곳, 레시피 6종 + 실패작, 버프(속도·방어·최대 하트, 최대 2개).
- **도감**: 물고기·몬스터·식물·아이템·보물·요리·지역 7분류, 실루엣 → 발견 순서·장소 기록, 수집률.
- **미니게임**: 활쏘기, 고리 달리기, 몬스터 퇴치 도전, 낚시 대회 (최고 기록 저장).
- **시간·날씨**: 하루 12분(아침·낮·저녁·밤), 맑음·흐림·비·안개, 밤에는 등불나방 출현, 주민 하루 일과(밤엔 귀가).
- **상점**: 사기·팔기·장비 강화(검·방패 3단계, 조개 + 광석).
- **동료·탈것**: 다친 늑대를 요리로 돌보면 동료가 되고 탈 수 있다(속도 1.75배).
- **지도**: 가 본 곳만 밝혀지는 전체 지도, 부엉이 석상 빠른 이동.
- **저장 v2**: 새 데이터 모두 저장, v1 저장 자동 변환, 직전 저장본 백업.

## 진행 (기존 요약)

1. 소라 할머니와 대화 → 2. 집 앞 상자에서 산호검 → 3. 옛 등대 폐허에서 돌을 밀어 문을 열고 바다불 등불 →
4. 물빛 동굴 (횃불 퍼즐, 돌 밀기 퍼즐, 나방의 방, 잠긴 문) → 5. 보스 가시고둥왕 → 6. 달빛 사원에 달진주.
선택: 이끼숲 덤불 뒤 소라 방패, 거울 호수 섬의 하트 그릇, 갈매기 절벽의 별 조각, 해변 조개 상자, 빵집에서 회복 열매 구매.

## 모바일 최적화
- 기기 자동 판별: GPU 이름·메모리·코어 수로 시작 품질 결정(대부분의 휴대폰은 "낮음"), 실행 중 프레임이 낮으면 한 단계 더 낮춤
- 동적 해상도: 프레임이 느리면 렌더 해상도를 60%까지 자동으로 낮췄다가 여유가 생기면 복구, 휴대폰은 픽셀 배율 최대 1.5배
- 60fps 상한(120Hz 화면에서 배터리 절약), 낮음 품질은 후처리 생략·그림자 반속 갱신·그림자 범위 축소
- 지형 타일 분할(화면 밖 생략) + 낮음 품질 절반 해상도, 나무·바위·덤불 거리별 저해상도 모델(LOD)과 거리 컬링
- 정적 소품(집·울타리 등)을 재질별로 합쳐 드로우콜 감소, 클로버 잎을 납작한 원판으로 교체
- 멀리 있는 몬스터·주민은 계산 생략, 미니맵 갱신 1/4, 바뀐 부분만 UI 갱신
- 세로 화면에서는 시야각을 넓혀 좌우가 좁아지지 않게, 불러오는 동안 로딩 화면
- `?perf` 없이도 `window.__perf`에 프레임별 갱신 시간·드로우콜·삼각형 수가 기록됨 (`scripts/perfm.mjs`)

## 테스트 스크립트
`scripts/`에 Playwright 기반 자동 플레이 테스트가 있습니다: `full.mjs`(던전까지 메인), `expansion.mjs`(확장 기능 28항목), `finale.mjs`(마지막 장과 엔딩), `mobile2.mjs`(모바일), `scenarios.mjs`(도달 가능성 검사).
