# 파도섬 이야기 (Wave Isle)

바람이 멎은 작은 섬에서 달진주를 되찾는, 3D 디오라마 스타일의 오리지널 액션 어드벤처 게임입니다.
TypeScript + Three.js(WebGL) + Vite로 만들었고, 외부 3D 에셋 없이 모든 모델, 셰이더, 음악, 효과음을 코드로 직접 생성합니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 에 배포용 빌드
npm run preview    # 빌드 결과 미리보기
node scripts/inline.mjs   # dist/wave-isle-single.html: 파일 하나로 된 버전
```

`dist/` 폴더를 정적 호스팅(GitHub Pages, Netlify, Vercel, S3 등)에 그대로 올리면 됩니다. 상대 경로(`base: './'`)로 빌드됩니다.
URL에 `?q=low|medium|high`를 붙이면 그래픽 품질을 강제할 수 있습니다.

## 조작

| PC | 모바일 | 동작 |
|---|---|---|
| WASD / 방향키 | 왼쪽 조이스틱 | 이동 (Shift 또는 스틱 끝까지: 달리기) |
| 마우스 오른쪽 드래그, 휠 | 화면 드래그, 두 손가락 | 카메라 회전, 확대/축소 |
| J / 마우스 왼쪽 | 공격 | 3단 콤보(3타 회전 베기), 공중에서 내려찍기 |
| Space | 점프 | 점프 |
| K | 구르기 | 회피 (무적 시간) |
| L | 방어 | 방패로 정면 막기 |
| Q | 도구 | 장착 도구 사용 (등불: 횃불 점화) |
| E / F | 조사 | 대화, 상자, 표지판, 문 |
| I / Tab | 가방 버튼 | 인벤토리 |
| Esc / P | Ⅱ 버튼 | 일시정지 (저장, 설정, 조작 방법) |

## 진행

1. 소라 할머니와 대화 → 2. 집 앞 상자에서 산호검 → 3. 옛 등대 폐허에서 돌을 밀어 문을 열고 바다불 등불 →
4. 물빛 동굴 (횃불 퍼즐, 돌 밀기 퍼즐, 나방의 방, 잠긴 문) → 5. 보스 가시고둥왕 → 6. 달빛 사원에 달진주.
선택: 이끼숲 덤불 뒤 소라 방패, 거울 호수 섬의 하트 그릇, 갈매기 절벽의 별 조각, 해변 조개 상자, 빵집에서 회복 열매 구매.

## 구조 (`src/`)

| 폴더 | 내용 |
|---|---|
| core | 게임 루프와 상태 (`Game.ts`), 이벤트 버스, 입력, 품질 프로필, 노이즈/수학 |
| render | 렌더러와 후처리 (GTAO, 블룸, 틸트시프트, 컬러 그레이딩, SMAA/FXAA), 공용 셰이더 머티리얼, 파티클, 접촉 그림자 |
| camera | 3인칭 쿼터뷰 리그 (궤도, 줌, 지형 회피, 화면 흔들림) |
| world | 하이트필드 지형, 지형 셰이더, 물, 식생 인스턴싱, 소품/건물 모델, 충돌, 배치 데이터 |
| character | 주인공과 주민 모델 (관절 계층), 플레이어 컨트롤러, NPC |
| animation | 절차적 애니메이터 (대기, 걷기, 달리기, 점프, 착지, 공격 3종, 내려찍기, 방어, 구르기, 피격, 사망, 아이템 획득, 상호작용) |
| combat | 공격 타이밍 테이블 (애니메이션과 판정 공유) |
| enemy | 몬스터 5종 모델과 AI (도토리딱정이, 버섯꼬마, 소라게, 등불나방, 보스 가시고둥왕) |
| item / inventory | 아이템 정의, 3D 아이템 모델, 3D 렌더 아이콘, 인벤토리와 장착 |
| quest | 진행 플래그, 목표, 대사 |
| puzzle / dungeon | 밀 수 있는 돌, 발판, 철문, 횃불 / 4개 방으로 된 던전 |
| ui | HUD, 미니맵, 대화창, 인벤토리, 메뉴, 타이틀, 엔딩 |
| audio | 실시간 합성 음악 (지역별 테마, 크로스페이드), 효과음, 환경음 |
| save | localStorage 저장과 설정 |
| mobile | 가상 조이스틱, 터치 버튼, 카메라 드래그, 핀치 줌 |

## 테스트 스크립트
`scripts/`에 Playwright 기반 자동 플레이 테스트(`full.mjs`, `scenarios.mjs`)와 스크린샷 도구가 있습니다.
